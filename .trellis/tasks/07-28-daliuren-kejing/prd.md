# 大六壬六十四课经实现

## Goal

以《钦定四库全书·六壬大全》卷七至卷十影印页为主底本，实现完整、可审计的六十四课经目录和匹配服务，使每个命中都能追到具体盘面事实、规则版本和古籍出处。

## Background

- 当前仓库没有六十四课经模型、目录或 evaluator。
- 本子任务依赖 `07-28-daliuren-classics-evidence` 提供经影印页核定的 64 条目录，依赖 `07-28-daliuren-rule-contract-history` 的稳定规则契约，并消费 `07-28-daliuren-pan-foundation` 与 `07-28-daliuren-sanchuan-enrichment` 的有类型盘面事实。
- OCR、现代转载和现有代码行为不能用来补齐条目或条件；证据不足的条目阻塞本子任务完成，不能用占位规则凑足 64 条。

## Requirements

- 规则目录恰好包含 64 个稳定课经 ID；每条记录题名、主底本卷页、短引文、解释、异文、证据等级、结构化适用条件和验证 fixture。
- 采用封闭的有类型条件集合并在生成阶段校验，不执行 JSON 中的任意表达式，也不靠中文说明匹配。
- evaluator 只消费统一的 `DaLiuRenFactSet`，输出 `DlrRuleHit<KeJingResult>`；命中依据必须列出实际使用的事实和决胜步骤。
- 同盘可保留所有真实命中；若底本定义互斥或主次关系，以目录中的结构化关系裁决并输出原因。
- 课经原文与程序摘要分开；用户展示文案变化不得改变匹配结果。
- 每条规则至少有一个来源独立的正例和一个能防止条件过宽的反例；生产算法不得参与生成测试预期。
- 旧盘版本不兼容时，匹配报告必须带兼容警示，不能把当前课经规则标成旧盘生成时已有事实。
- 本子任务提供领域模型、生成目录、匹配服务和基础 formatter/view projection；完整结果页编排由最终集成子任务收口。

## Acceptance Criteria

- [ ] 目录校验确认规则数恰为 64，所有 ruleId 唯一、sourceRef 可解析、卷页完整且证据至少为 B。
- [ ] 64 条规则均能从结构化源数据生成强类型 Dart 条目，生成结果无手写漂移。
- [ ] 每条规则均有正例、反例和逐条测试；测试预期能追到具体影印页或核定外例。
- [ ] evaluator 不读取展示中文作为执行键，且打乱目录输入顺序不会改变稳定输出顺序。
- [ ] 同盘多命中、互斥、主次、无命中和旧盘不兼容状态均有测试。
- [ ] 课经命中经 JSON round-trip 后保持 ruleId、版本、证据和结构化依据一致。
- [ ] 定向静态检查和单元测试通过，未改变基础排盘结果。

## Out Of Scope

- 不在本子任务中实现毕法百法、类神、本命行年或最终综合断课。
- 不把 64 条未命中原文全部堆到单次结果页；全目录浏览不是本次验收目标。
- 不为证据不足的传本差异增加运行时配置。
