# 大六壬毕法赋百法实现

## Goal

以《钦定四库全书·六壬大全》卷十一至卷十二为主底本，完整实现毕法赋一百法的证据目录、结构化匹配、组合冲突和逐条回归，使同一课中的多法命中可解释、可复核、可稳定输出。

## Background

- 当前仓库没有毕法赋规则模型或服务，现有十行裁决表不能替代毕法百法。
- 本子任务依赖古籍证据、稳定规则契约和已完成的基础盘/神煞/三传/课经事实；目录未核页或依赖事实未实现时不得用近似文案代替。
- 毕法可以一盘多命中，必须显式处理组合、互斥和主次，不能采用“首行命中即返回”的现有裁决方式。

## Requirements

- 目录恰好包含 100 个稳定毕法 ID、序号、题名、卷页、短引、解释、证据等级、typed 条件、组合/互斥关系及 fixture。
- JSON 条件只允许证据子任务批准的封闭 predicate schema；禁止任意表达式和中文字符串执行键。
- evaluator 评估全部适用法，输出 `BiFaReport` 和完整 fact trace；未命中、缺事实、版本不兼容必须区分。
- 多法命中默认全部保留；只有目录明确的互斥/覆盖关系才能抑制，且必须输出 `DlrRuleConflict`。
- 每法至少有一个独立正例和一个防过宽反例；高风险组合另有完整盘 fixture。
- 毕法命中本身不是最终吉凶结论；传统断课子任务按占类和证据化优先级消费 ruleId。
- 基础 formatter 输出结构化百法命中和证据；最终结果页、AI 文本和跨层排序由集成子任务收口。

## Acceptance Criteria

- [ ] 目录校验确认恰为 100 法，序号/ruleId 唯一，sourceRef、卷页、证据和 fixture 完整。
- [ ] 100 法全部生成强类型 predicate 并逐条通过正例、反例测试，无占位或恒真规则。
- [ ] 同盘多法、互斥、覆盖、并列、无命中、缺事实和旧版本状态有明确测试。
- [ ] 匹配输出排序在目录顺序变化后仍稳定，冲突不会因 first-match 被静默丢失。
- [ ] 每个命中可追到实际盘面 fact、目录版本和影印页，展示文案改变不影响规则行为。
- [ ] 定向 analyze/test 通过，且不会改变基础盘、课经或神煞事实。

## Out Of Scope

- 不在本子任务中给百法建立脱离占类的单一“总吉凶分数”。
- 不把所有传本异文做成配置；未采用异文保留在证据目录。
- 不以现代毕法口诀释义替代卷十一、十二的影印页核定。
