# 大六壬古籍证据源初步清单

## 结论

当前仓库没有可供逐页核验的六壬原典，只有项目文档中的书名级引用和手工推演课例。现有实现不能仅凭“参考《大六壬指南》”认定为古籍已验证。

本清单只登记 2026-07-28 已通过公开馆藏 API 确认可访问的底本。OCR 质量不足，只能辅助定位；最终规则引文必须回到影印页，记录卷次、影印页和原文。

## 仓库内证据

- `docs/大六壬排盘案例.md`：项目说明与模拟课例，不是古籍或外部校验课例。
- `.trellis/spec/domain/daliuren-pan-engine.md`：项目锁定口径，引用《大六壬指南》但没有版本、卷页或逐条原文。
- `.trellis/spec/domain/daliuren-analysis-engine.md`：明确声明裁决表和多数标签为“本项目约定（大六壬断课 v1）”。
- `.trellis/tasks/archive/2026-07/07-27-daliuren-sanchuan-fix/design.md`：13 个手工推演的位移盘，适合回归实现分支，但不是已出版课例的独立预期值。
- 仓库内未发现 `.pdf`、`.epub`、`.mobi` 或 `.txt` 格式的大六壬古籍文件。

## 建议的证据等级

| 等级 | 含义 | 可作为实现依据 |
|---|---|---|
| A | 明确版本的古籍影印页 + 可复算课例，且至少一个独立底本交叉一致 | 是，默认口径 |
| B | 单一古籍影印页或多底本规则一致但无完整课例 | 是，需补边界测试并标注版本 |
| C | 现代校注、讲义或项目手工推演，与原典方向一致 | 只能辅助解释和测试设计 |
| D | 博客转载、无版本 OCR、现有代码行为或 AI 推断 | 否 |
