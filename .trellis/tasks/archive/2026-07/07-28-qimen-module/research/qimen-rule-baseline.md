# 奇门遁甲规则与校盘研究基线

## 结论

- 项目采用时家转盘奇门，拆补法为默认，另支持茅山法、置闰法与手动校盘。
- `lunar 1.7.8` 只负责精确节气、干支与时支等历法事实；奇门定局和排盘必须由项目内纯 Dart 服务实现。
- Pub.dev 没有可直接采用并满足本任务范围的成熟奇门引擎。外部 MIT 项目仅用于交叉核验与发现边界，不能把其中任一实现当成唯一权威。
- 所有分歧口径必须写入 `QimenPanParams` 并随结果持久化；禁止只在 UI 状态中保留。

## 仓库能力

- `lib/domain/services/shared/lunar_service.dart` 已封装 `lunar`，但当前使用的非 Exact 日月柱不足以直接作为奇门时间上下文。
- `lunar` 的 `getPrevJieQi(false)` / `getNextJieQi(false)` 可返回精确交节时刻。
- `lunar.getDayInGanZhiExact()` 在 23:00 换到次日；`getDayInGanZhiExact2()` 在 00:00 换日。
- `lunar.getTimeInGanZhi()` 始终按 23:00 换日的日干计算。选择 00:00 换日时，时干必须由选定日干与时支重新计算，不能直接复用该 getter。
- `TianGanDiZhiService` 已提供十干、十二支、六十甲子、合法性校验与旬空计算，应复用而不是复制常量。

## 锁定的定局规则

### 共同规则

- 交节以实际排盘时间对应的精确节气时刻为边界，不按整日切换。
- 冬至起阳遁、夏至起阴遁；局数使用二十四节气上中下元固定表。
- 手动校盘可显式覆盖四柱、节气、阴阳遁、局数与三元，并标记为 `CastMethod.manual`。
- 自动结果保存推导轨迹：生效时间、节气及交节时刻、符头、三元、阴阳遁、局数、定局法与置闰状态。

### 拆补法（默认）

1. 按选定换日规则取得日干支。
2. 从当日回溯到最近的甲日或己日作为五日符头。
3. 符头支为子午卯酉取上元，寅申巳亥取中元，辰戌丑未取下元。
4. 精确交节后立即使用新节气局数表；残元按新节气补足，故不跨节气沿用旧局。

### 茅山法

1. 以精确交节所在时辰的起点作为该节气上元起点。
2. 上元、中元各 60 个时辰（120 小时）；其后为下元，延续到下一次精确交节。
3. 阴阳遁及局数从当前节气对应三元表取得，不使用符头。

### 置闰法

1. 三元仍以十五日上元符头周期为基础，并记录超神/接气关系。
2. 上元符头早于交节为超神，晚于交节为接气；平时按符头切换三元周期。
3. 累积超神超过九日时，只允许在芒种或大雪增加一次完整十五日闰周期，重复该节气上、中、下三元局，以便在夏至或冬至重新对齐。
4. 置闰判定必须由日期与符头/节气关系动态计算，禁止用硬编码年份个位表替代。
5. 由于公开实现分歧最大，置闰服务必须拥有跨置闰前、闰周期内、二至后重新对齐的来源化黄金样例；无法通过黄金校验时不得启用该选项。

## 锁定的转盘规则

- 洛书布局：`4-9-2 / 3-5-7 / 8-1-6`。
- 三奇六仪次序：戊、己、庚、辛、壬、癸、丁、丙、乙；阳遁顺飞九宫，阴遁逆飞九宫。
- 六甲遁仪：甲子戊、甲戌己、甲申庚、甲午辛、甲辰壬、甲寅癸。
- 九星本位：蓬1、芮2、冲3、辅4、禽5、心6、柱7、任8、英9；转盘外八宫次序为蓬、任、冲、辅、英、芮、柱、心。
- 八门本位：休1、生8、伤3、杜4、景9、死2、惊7、开6；中宫无门。
- 八神次序：值符、螣蛇、太阴、六合、白虎、玄武、九地、九天；阳遁顺布、阴遁逆布。
- 默认寄宫为中五寄坤二、天禽随天芮；兼容口径为阳遁寄艮八、阴遁寄坤二。
- 默认暗干为值使落宫起时干，阳顺阴逆飞九宫；兼容口径为当前门的本位宫地盘干。
- 值符为时旬首遁仪本位星并随时干落宫；值使为同一本位宫之门，按旬首到时支步数阳顺阴逆飞宫；落中五时按所选寄宫口径处理。

## 时间基准

- 当地民用时间：使用输入瞬间在设备时区的墙上时间与该日 UTC offset。
- 北京时间：把同一瞬间转换为 UTC+08:00 后取墙上时间。
- 真太阳时：以当地民用时间为基准，校正分钟数为 `4 * (longitude - standardMeridian) + equationOfTime`；标准经线为 `UTC offset hours * 15`。方程时使用固定、版本化的 NOAA 近似公式，并把总校正分钟与算法版本写入结果。
- 输入、标准时间和校正后时间都必须保留；历史重开不得依赖设备当前时区重新推算原始盘。

## 黄金测试政策

- 每个黄金案例记录：时间基准、输入时间、四柱、节气/交节时刻、定局法、口径参数、预期九宫、来源、版本/访问日期及人工裁决说明。
- 至少包含：拆补阴阳遁各两盘、茅山三元边界各一组、置闰前/闰中/二至后各一组、旬首六仪六类、值符或值使落中五、两种寄宫、两种暗干、节气前/当刻/后一秒、23:00 与 00:00 换日。
- 外部软件快照必须由两个独立实现一致，或由公开课例逐项手工推演后才可成为断言；单一仓库的自测不能独立充当权威。
- 除端到端黄金盘外，各计算阶段必须有小型表驱动单元测试和 JSON 深比较往返测试。
