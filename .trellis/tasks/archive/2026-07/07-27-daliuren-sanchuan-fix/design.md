## 2. 四课克判定修正（`SiKeService`）

- 每课独立判定两方向：下神五行克上神五行 → `isZeiKe=true`（下贼上）；上神克下神 → `isBiYong=true`（上克下）。与 `Ke` 模型注释一致（模型注释是对的，服务赋值是反的）。

## 3. 三传推导总流程（`SanChuanService.deriveSanChuan`）

```
1. 若天地盘同位        → 伏吟法（§4.8）
2. 若天地盘对冲        → 反吟法（§4.9）
3. 若为八专日（干寄宫==日支，即甲寅/庚申/丁未/己未/癸丑）
     且四课无上下克    → 八专法（§4.7）
     （八专日有克 → 走第 4 步普通贼克流程，课体仍标 baZhuan，说明中注明"八专有克，取克发用"）【分歧：有派标贼克】
4. 四课有下贼上        → 贼克（§4.1）；多者 → 比用（§4.2）；比用不唯一 → 涉害（§4.3）
5. 无下贼上、有上克下  → 贼克（§4.1）；多者 → 比用；不唯一 → 涉害
6. 四课全无克          → 遥克（§4.4）
7. 无遥克、四课全（四课上神各异）→ 昴星（§4.5）
8. 无遥克、四课不全（三课备）    → 别责（§4.6）
```

中末传通用规则（除伏吟、昴星、别责、八专、反吟无克外）：**中传 = 天盘上初传所临之上神 = tianPanMap[初传]；末传 = tianPanMap[中传]**。

## 4. 九宗门细则

### 4.1 贼克

- 下贼上（下克上）课**优先**于上克下课："取课先从下贼呼，如无下贼上克初"。
- 初传 = 所选课的**上神**（两种方向都取上神）。
- 仅一课下贼上 → 直接发用（课体 zeiKe，传统名：重审）。
- 无下贼上、仅一课上克下 → 直接发用（课体 zeiKe，传统名：元首）。`keTypeExplanation` 注明"下贼上/上克下"及传统课名。

### 4.2 比用

- 同方向候选多于一课时（多个下贼上，或无下贼上时多个上克下），取上神与日干**俱比**（阴阳相同）者。
- 恰一候选相比 → 发用，课体 biYong（传统名：知一）。
- 俱比或俱不比（0 个或 ≥2 个相比）→ 涉害。
- 注意：候选集只在同方向内部比较；有下贼上时上克下课全部不参与。

### 4.3 涉害

候选 = 比用阶段未决的那组上神。对每个候选：

- **涉害深度**：候选神从其所临地盘宫起（**含**所临宫），顺时针历数各宫至其本家地盘宫止（**不含**本家宫）。每经一宫，该宫的**地支本气**与该宫**所寄天干**（§1.2 反查表）中，五行克候选神者，每一项计一害。深者胜。
- 深度并列 → 取所临地盘宫为**四孟**（寅申巳亥）者（传统名：见机）；无孟 → 取**四仲**（子午卯酉）者（察微）；仍并列 → 刚日（阳干）取干上神（第一课上神），柔日取支上神（第三课上神）（缀瑕/复等）。【分歧：有派孟仲计数即止】
- 中末传按通用规则。课体 sheHai，说明含各候选深度数值。

### 4.4 遥克

四课上下无克时，取**第二、三、四课上神**与日干遥克（第一课上神与日干之克已在贼克阶段穷尽）：

- 先取**上神克日干**者（蒿矢）；无，则取**日干克上神**者（弹射）。
- 候选多者取与日干俱比者；仍不唯一 → 取课序在前者。【分歧：极罕见情形，各派记载简略】
- 中末传按通用规则。课体 yaoKe，说明注明蒿矢/弹射。

### 4.5 昴星

四课全（上神四位各异）、无上下克、无遥克：

- 刚日（阳干）：初传 = 地盘酉宫上神 = `tianPanMap['酉']`（虎视）；中传 = 支上神（第三课上神）；末传 = 干上神（第一课上神）。
- 柔日（阴干）：初传 = 天盘酉所临之地盘支（即 tianPanMap 反查 酉 的键，冬蛇掩目）；中传 = 干上神；末传 = 支上神。
- 歌诀："阳仰阴俯酉位中，刚日先辰而后日，柔日先日而后辰"。课体 maoXing。

### 4.6 别责

四课不全（三课备，即四课中有两课上下神全同）、无上下克、无遥克：

- 刚日：初传 = 日干五合之干的寄宫**上神** = `tianPanMap[寄宫(合干)]`（"刚日干合上头神"）。【分歧：有派取寄宫本位支】
- 柔日：初传 = 日支三合局**前辰**（§1.7 下一位，直接用该支）。
- 中传 = 末传 = 干上神（第一课上神）。课体 bieZe。

### 4.7 八专

八专日（甲寅/庚申/丁未/己未/癸丑）且无上下克：

- 阳日：初传 = 自干上神（第一课上神）在地支序上**顺数三位（含本位）**，即 干上神+2。
- 阴日：初传 = 自第四课上神**逆数三位（含本位）**，即 第四课上神−2。
- 中传 = 末传 = 干上神。歌诀："阳日日阳顺行三，阴日辰阴逆三位，中末总向日上眠"。课体 baZhuan。

### 4.8 伏吟

天地盘同位（tianPanMap 恒等）：

- 有上下克：初传 = 克课上神（下贼上优先，同 §4.1；多者比用裁选）。
- 无克：刚日初传 = 干上神（自任）；柔日初传 = 支上神（自信）。
- 中末传走**刑传链**（不用天盘链）：
  - 中传 = 初传所刑之支（§1.4）；若初传**自刑**（辰午酉亥），中传 = 刚日取支上神 / 柔日取干上神（"次传颠倒日辰并"）。
  - 末传 = 中传所刑之支；若中传**自刑**，末传 = 中传所冲之支（"次传更复自刑者，冲取传来"）。
- 课体 fuYin，说明注明 自任/自信/有克 及刑传路径。

### 4.9 反吟

天地盘对冲（tianPanMap[x] = 冲(x)）：

- 有上下克：初传按 §4.1/§4.2/§4.3 流程裁选（取**上神**——修复现行取下神的 bug）；中末传按通用天盘链（自然形成 初-冲-初 结构）。
- 无克（仅丁丑、己丑、丁未、己未四日会出现）：初传 = 日支**驿马**（§1.6）；中传 = 支上神；末传 = 干上神（井栏射）。
- 课体 fanYin。
