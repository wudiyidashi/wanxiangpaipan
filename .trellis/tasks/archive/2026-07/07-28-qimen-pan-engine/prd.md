# 奇门遁甲排盘与历法引擎

## Goal

建立可独立测试、可序列化、可供分析与 UI 稳定消费的时家转盘奇门领域引擎，完整实现时间归一化、拆补/茅山/置闰定局、手动校盘和九宫排布。

## Dependency

- 无代码依赖；这是奇门任务树的首个实现子任务。
- 规则与校盘基线继承父任务 `07-28-qimen-module/research/qimen-rule-baseline.md`。

## Requirements

### P1 系统与输入合同

- 新增稳定系统类型 `DivinationType.qiMen('奇门遁甲', 'qimen')` 和 `QimenSystem`，但本子任务不把它注册到发布入口。
- 支持 `CastMethod.time` 与 `CastMethod.manual`，`supportedMethods`、`validateInput()` 与实际 payload 完全一致。
- `time` 接收类型化 `params`；缺省采用拆补、当地民用时间、子初换日、中五寄坤二和值使起暗干。
- `manual` 必须显式提供完整四柱、节气、阴阳遁、局数与三元，可复用同一套寄宫/暗干参数。

### P2 时间上下文

- 实现当地民用时间、北京时间、真太阳时三种基准与子初/午夜两种换日规则。
- 真太阳时同时包含经度差和版本化方程时校正，经度限制 `[-180, 180]`。
- 使用精确节气时刻和 Exact/Exact2 四柱；午夜换日模式在 23:00-23:59 重新计算时干。
- 结果保存所有输入、转换与历法事实，不依赖设备当前时区复算。

### P3 定局策略

- 单一局数表作为拆补、茅山、置闰共用数据源。
- 拆补：甲/己五日符头定三元，精确交节后切换新节气局。
- 茅山：交节所在时辰起上元，上中元各 60 时辰，下元续至下一交节。
- 置闰：动态计算超神接气；超神超过九日且仅在芒种/大雪插入十五日闰周期。
- 手动校盘跳过自动定局，但输出同构 `QimenJuInfo` 和推导轨迹。

### P4 完整转盘

- 实现地盘三奇六仪、时旬首遁仪、值符值使、天盘九星、八门、八神、暗干、中五寄宫、旬空与驿马。
- 默认/兼容寄宫和暗干口径均由稳定 enum 参数控制。
- 九宫事实强类型化；每宫包含宫位元数据、天地盘干、寄宫干/星、九星、八门、八神、暗干、空亡/驿马和基础标记。
- 计算阶段均为纯静态服务，`QimenSystem` 只负责校验、编排与结果组装。

### P5 结果与持久化

- `QimenResult` 完整实现 `DivinationResult`，JSON 使用稳定 ID 并包含 `schemaVersion=1`。
- `toJson()` / `fromJson()` 深比较可逆，包含全部参数、时间、定局、九宫和推导事实。
- 摘要固定为“阴/阳遁N局 · X值符 / X门值使”。
- 通过现有通用仓储完成保存、读取、按系统查询和最近记录往返，不新增数据库表。

### P6 文档与测试

- 新增 `docs/architecture/divination-systems/qimen.md` 的排盘合同及 `.trellis/spec/domain/qimen-pan-engine.md`。
- 建立来源化黄金案例、阶段表驱动测试、时间边界测试、参数/输入矩阵与仓储往返测试。

## Acceptance Criteria

- [ ] `time` 和 `manual` 的全部合法输入成功、非法输入拒绝且无静默默认四柱。
- [ ] 三种自动定局法与手动覆盖返回结构一致、推导轨迹完整。
- [ ] 节气前/当刻/后一秒、23:00/00:00、三种时间基准和真太阳时校正具有固定测试。
- [ ] 九宫编号 1-9 唯一齐全；默认与兼容寄宫/暗干盘均通过黄金或阶段断言。
- [ ] 六种旬首遁仪、阴阳九局、值符/值使落中宫、旬空与驿马均被测试覆盖。
- [ ] `QimenResult` JSON 深比较及 Drift 仓储往返一致。
- [ ] 系统级文档、domain spec、代码与测试口径一致。
- [ ] `flutter analyze`、奇门排盘目标测试和全量 `flutter test` 通过。

- 飞盘、阴盘、年家、月家、日家奇门。
