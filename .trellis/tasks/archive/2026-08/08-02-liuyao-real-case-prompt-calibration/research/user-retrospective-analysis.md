# 用户实盘复盘分层

## 1. 用户给定裁决口径

- 问题：租房是否顺利。
- 主取用：初爻妻财未土；上爻妻财戌土为同六亲另一现。
- 期望综合裁决：**事必成，成而受困；合非吉兆，是套。**
- 核心方法：把“事情是否形成”与“形成后的质量、成本和持续性”分开，不能把签约成功等同全程顺利。

本文件记录用户复盘和校准边界，不是古籍证据。生产 generation prompt 不得包含已知结果或本文件中的事后对应；这些内容只允许进入 reference/judge。

## 3. 当前规则与用户复盘的明确冲突

### 3.1 回头克被错误压平成“立即无作用”

current v2 让三爻卯木因本位化申回头克而进入 suppressed，继而把“卯木动克初爻未土”标为 inactive。用户复盘口径是：卯木在前段仍发动并造成催促、竞争和费用压力，回头克描述其后续受制，不能抹掉先发生的作用。

v3 必须表达时间阶段：本卦动爻的初始外向作用与变爻回头作用并存；后者可限制持续性或最终状态，但不得无条件删除前者。该语义在完成本地古籍页级核验前标为项目约定，不伪造引文。

### 3.2 单一四值趋势无法表达本案

初爻妻财 current v2 verdict 为 `buMing / 扶抑并见`；伏神父母 current v2 verdict 为 `daiTiaoJian / 先难后成`。二者都不能表达“交易形成，但形成后受损且不能持续”。

v3 需要至少拆分：

- formation：关系/交易是否形成；
- quality：形成后的得失和顺逆；
- continuity：完整租期能否维持；
- persistence：关系是顺畅延续还是不利纠缠。

六合可支持 formation/persistence，但不能单独决定 quality。主证据不利时，六合表现为合住、牵绊、困局持续，而非吉兆。

### 3.3 动空的机械效力与象意必须分开

本地已核验《增删卜易》旬空章口径为“动不为空”，所以戌土发动只能判假空，不能在机械作用层说成完全不存在。用户提出的“虚、假、巧立名目收费”可以作为低权限象意，较稳妥的泛化表述是“费用名实、收费依据或兑现存在核验风险”，不得据此断言必有虚假收费。

## 4. 用户复盘的解释层映射

以下均为校准解释，不得伪装成程序事实或古籍原文：

| 盘面组合 | 可泛化风险提示 | 禁止直接猜测的已知结果 |
|---|---|---|
| 旺相兄弟发动克财，临朱雀 | 竞争、口头催促、费用分流、宣传或争执风险 | 有人抢同一套房、黑中介催定金 |
| 妻财两现；上财动空、白虎、化绝 | 多项付款、收费名实、资金追索和损失风险 | 两笔钱、虚假收费、具体损失金额 |
| 父母不上卦而伏、飞克伏 | 房屋/合同/产权/身份文书不透明，须核验出租权 | 必然是二房东 |
| 世财月克、死；旺忌发动克世 | 求测者资金和承受能力受压，事情虽发生但代价不利 | 必然被骗多少金额 |
| 应生世而应入动墓 | 前期好谈或对方示利，后续履约、联络或持续性有隐患 | 对方必在某月跑路 |
| 豫变旅 | 可作“前段安顿、后段寄居不稳”的低权限卦名象意 | 必然住三个月后被赶出 |

六神、卦名和世应象意若没有本地页级来源，只能标为 interpretive/project convention；它们可细化风险性质，不得越权单独反转主裁决。

## 5. 生产与评测边界

- generation 输入：问题、规范化排盘、用户选择初爻妻财、完整全爻事实、版本化规则和阶段裁决。
- generation 禁止输入：二房东、黑中介、六个月房租、住三个月、甲午月跑路、被赶出、损失三千余元，以及用户事后映射原文。
- judge/reference 可读取实际结果和本文件，用于评估候选是否识别了出租权、费用、履约和持续性风险。
- 命中“二房东跑路”“损失三千”等无输入精确事实仍按过拟合/幻觉扣分。
