## Implications For Implementation

1. Register each source by stable source ID, edition description and SHA-256; never store the absolute local path in production output.
2. Store short bounded witnesses only after page-level visual verification. Distinguish exact quote, paraphrase, source case, project convention and locator-only evidence.
3. Attribute the four-value verdict table, strength classification and first-match policy to a project-convention source, while linking its component predicates to the verified classical witnesses that actually support them.
4. Do not expand the corpus merely to increase book count. The locked hierarchy remains 《增删卜易》 primary and 《卜筮正宗》 low-priority supplement.
