# 发布说明

### 2026-08-03 · v1.6.1 - v1.6.4

- 设置页“关于”弹窗现在读取安装包的实际版本与构建号，不再固定显示 `1.0.0`；无法读取系统信息时会明确显示未知版本。
- GitHub Release 恢复自动构建并提供 Android APK 和 AAB，APK 可直接下载安装，AAB 可用于应用商店发布；附件路径会在发布时强制校验，缺失时不再生成看似成功的空 Release。
- 六爻对“是否顺利”类问题新增形成、得失、持续性和纠缠四阶段裁决。事情能签成、开始或入住只代表形成，不再自动等同为最终顺利。
- 六合和卦变六合改为随主证解释的关系黏合、合住、牵绊与持续，只能参与形成和纠缠判断，不能单独决定得失或整体吉凶；主证不利时可明确表达“事成而受困”。
- 本卦动爻的前段作用与变爻的后段限制分别记录。回头克、化退、化绝等后果只限制后续或最终状态，不再追溯抹掉已经发生的竞争、费用或其他前段作用。
- 结构化分析现在稳定覆盖六个本卦爻、对应变爻、伏神、同六亲另一现、世应关系、六神和卦名，并为机械事实、古籍转述和项目象意划分不同权限。
- 租房问题会分别回答能否签约或入住、出租权与合同主体是否可靠、收费是否完整合理、能否交付占有及完整租期能否持续；不会猜测盘面中不存在的具体身份、行为、月份、周期或金额。
- 未选用神时 AI 会停止总体成败与吉凶判断，只给候选用神和待核验维度；选定用神且程序形成阶段裁决后，才按固定顺序解释形成、得失、持续性与纠缠。
- 卦名卦阳历模式会保存用户实际选择的起卦时间，并区分阳历推导、直接四柱、人工覆盖和旧记录来源，避免记录时间与分析四柱错配。
- 无条件、无应期的新提示词只保留当前盘面事实和已授权裁决，不再从程序审计摘要扩写等待、择日、未来释放路径或新日期；有真实应期候选时仍保留观察窗口边界。
- 本版本以一个已知结果的租房案例作为校准集，并回跑三个代表古例；本地同模型的 6 组租房配对与 9 组代表古例配对均通过硬门禁。正式 40×3 holdout 未运行，单个校准案例不代表现实预测准确率。

### 2026-08-02 · v1.6.0

- 六爻分析升级为固定、可追溯的古籍规则体系，以《增删卜易》为主要裁决依据；《卜筮正宗》的三刑、六害仅作低优先级补充，证据不足时不会参与决定性判断。
- 用户选定的用神始终优先。程序会依次分析日月旺衰、空破墓绝、动变、伏神、作用者是否可用及有向生克，再形成唯一的趋势裁决、反证与完整未决条件。
- 应期现在只从仍可解除的条件生成，并明确是观察窗口而非结果承诺；日尺度候选进入日历角标和日详情，月尺度候选在月建命中时显示整月提示。
- AI 解读采用完整的结构化分析投影，涵盖用神自身事实、原神与忌神、有效或受制的作用链、裁决因素、全部条件、应期和实际引用来源。
- 所有六爻 AI 模板都受不可移除的边界保护：AI 不得重算盘面、重选用神、覆盖程序裁决、补造应期，或编造古籍原文和页码；自定义模板同样遵守。
- 术语说明可查看规则来源、书名或项目约定、章节或印刷页、采用释义及证据边界；页级短引、转述、项目约定和仅定位内容会使用不同标识。
- 新建或重新生成的对话使用新版分析和提示词，既有对话继续逐字保留原提示词，并显示其冻结版本，避免历史解读被静默改写。
- 新增显式启用的真实模型配对评测工具，以同一批古例检查事实忠实、条件完整、来源引用、应期边界和解释质量，并在缺少有效配置时明确保持未评测状态。

### 2026-07-28

- 奇门遁甲完整上线，支持自动时间起局和手动四柱校盘，可选择拆补、茅山、置闰、真太阳时、换日、寄宫和暗干口径。
- 结果页新增固定洛书九宫、九个可交互宫位详情、值符值使与关键标记，并完整展示本地规则裁决、焦点、事实、冲突、来源和应期观察窗口。
- 当日干等关键焦点无法唯一定位时，结果页会明确显示诊断并暂停 AI 解读，完整盘面仍可继续查看。
- 奇门记录可保存并从历史完整重开，支持按系统统计、独立清理、全量导入导出和恢复。
- 新增奇门系统、综合和简要三类 AI 模板；AI 只解释程序排盘和裁决，分析不兼容或服务未配置时会明确提示且不影响本地盘面。
- 覆盖导入会在清理现有数据前完成完整校验，损坏记录会被单独报告，不再阻断同一备份中的合法记录；当前 AI 对话也会随备份恢复。
- 用户选择的 AI 模板在应用重启后保持不变，奇门对话使用稳定系统标识并兼容已有记录。
- 大六壬月将现在严格按北京时间的中气交接时刻切换，不再在交节当天零点提前换将；时间、报数和电脑起课在同一时刻使用一致月将。
- 大六壬会固定保存起课来源时差，起课预览、结果页、历史恢复和 AI 解读共享同一套四柱、中气与月将事实，跨设备查看不会因本地时区变化而漂移。
- 手工四柱起课须显式指定月将并校验年月、日时干支联动，也可使用民用时刻进行完整历法校验；旧版和无新增字段的历史盘仍可读取及备份恢复。
- 大六壬天盘与四课现在只接受完整且逐宫顺布的十二支盘面；缺宫、重复、乱序或月将未加临时支时会明确失败，不再补成本支或贵人。
- 三张《大六壬指南》独立手排课例已用于校对四课上下神；进入三传前还会复核课序、上下神链和克向，避免错误盘面继续推导。
- 大六壬贵人和十二天将现已分别记录昼夜所选贵人、贵人所临地宫与实际顺逆，不再把夜贵直接当作逆布，也不会把天盘支误作地盘落宫。
- 四课、三传、圆盘、结果页和 AI 解读统一使用同一套天盘乘将与地盘落将事实；旧版盘面仍按原记录读取，不会被当前排将规则静默重算。
